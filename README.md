# Kiyotada Mori — Personal Academic Website

Bilingual personal academic website for Kiyotada Mori, focused on spoken dialogue systems and real-time human–AI interaction.

## Structure

- `index.html` — content and page structure
- `styles.css` — responsive visual design
- `script.js` — English/Japanese language switching
- `AGENTS.md` — maintenance instructions for coding agents
- `.nojekyll` — serves the repository as a plain static site on GitHub Pages

## Local preview

Open `index.html` directly, or serve the directory with any static HTTP server.

## GitHub Pages

The site is designed to publish directly from the repository root. In the repository settings, enable GitHub Pages and choose the `main` branch / root directory, or configure a Pages workflow if preferred.

Note: GitHub Pages availability for a private repository depends on the GitHub plan. Making the repository public is the simplest option when appropriate.

## Updating

Academic facts should be updated from the latest CV or explicit user-provided information. Keep the Japanese and English versions synchronized.
